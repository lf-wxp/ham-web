# 取数规则（与页面脚注一一对应，改数据前先读）：
#   - 宽间隔一律取页面里的 20 kHz 一列；噪声底取**未开前放**那个值（页面用 b / b1 脚注标前放状态）；
#   - 一个格子里有多个值时取**第一个**（页面用 ab / ac 脚注区分 IP+ 与 dither 状态）；
