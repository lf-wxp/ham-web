### 1.2 概念：S9 CONSOLE / S9 值机台

> 把备考做成一次调谐 —— 搜索 → 锁定 → 读数 → 通联。「S9 = 合格线」直接取自站点文案，是唯一可记忆的识别点。

| 功能 | 视觉语义 |
|---|---|
| A/B/C 题库、题目分类 | 波段 / 频点（BAND、1.8–28 MHz 刻度） |
| 练习、筛选、切题 | 调谐 TUNE、扫描 SCAN |
| 选中选项、答对 | 捕获 / 锁定 LOCK、信号清晰 |
| 正确率、备考水平 | S 表读数（S1–S9 +20dB） |
| 错题、薄弱项 | 噪声底、QRM 干扰尖峰 |
| 复习、滤波器 | 降噪、FILTER ON |
| 模拟考 | 通联窗口 TX WINDOW、七段倒计时 |
| 28 天记录、成就 | 瀑布图日志、QSL 卡式勋章 |

### 1.3 三条一致性铁律与直观性约束

1. **单一行动色**：橙只给「开始 / 提交 / 发射」；蓝=选中位置、绿=正确信号、红=告警、金=成就，按现有 `--md-*` 角色分工，不得混用。
2. **三层信息密度**：底噪层（24px 网格 + 1px 扫描线 ≤15%，且只在仪器区）→ 仪器层（面板 / 刻度 / 读数）→ 内容层（题干正文，最高对比、零装饰）。文字永远在最上层。
3. **单一组件语法**：控件 40/30px、圆角 4/6/8/10/14px、动效 120/180/320ms、2px 断开虚线焦点环。

页面密度三档：Landing 沉浸、Practice / Lab 仪器、Read / Index 阅读。**直观性**：旋钮旁必有数值读数与单位；指示灯旁必有 10px 文字标签；颜色永不单独承载状态；反馈走「视觉 + 文字 + ARIA」三通道（`aria-busy` / `aria-invalid` / `aria-live`）；键盘路径保留 `⌘K` / 数字键 / 方向键；加载用扫描线而非转圈；空态画「NO SIGNAL」底噪屏；`prefers-reduced-motion` 压到 1ms 且内容始终可见。

## 2. 全局设计规格（唯一事实源）

### 2.1 视觉风格

现代 SDR 收发信机控制台，正交平视、无透视、无景深、无设备外壳；克制、精密、适合长时间阅读。仪器感来自刻度、读数与阻尼，不来自拟物堆砌。材质：近黑夜航底 + 拉丝铝旋钮 + 深凹示波屏 + 1px 冷光边；单一顶部柔光，禁止大面积渐变与玻璃拟态。浅色档是同一套语言的「白天模式」：纸白底、去辉光、扫描线降到 4%、几何完全不变。

### 2.2 配色方案

| 角色 | 深色值 | 浅色值 | 只允许出现在 |
|---|---|---|---|
| 底 / 面 / 面2 | `#04050A` / `#0B0D13` / `#12151E` | `#F4F3EE` / `#FFFEFB` / `#ECEBE4` | 页面与面板 |
| 墨 / 描边 / 网格 | `#F2F4FA` / 1px 冷灰 / 4% | `#0A0B0D` / `#D8DEE9` / 4% | 文字、分隔、24px 工程网格 |
| **行动色·信号橙** | `#FF6A3D` | `#FF4D1F` | 唯一 CTA、峰值游标、S9 合格线、扫描线 |
| 选中·电光蓝 | `#6F8CFF` | `#2540FF` | 选中态、当前位置、焦点语义 |
| 氛围·紫 | `#A97BFF` | `#5B2BFF` | 辉光，面积 <5% |
| 正确 / 信号·磷光绿 | `#35E39F` | `#00734F` | 判对、主波形、达成 |
| 告警红 / 成就金 | 按 `danger` / `gold` 令牌 | 同语义低饱和 | 错误、噪尖、勋章描边 |

辉光只出现在描边、指针、峰值与指示灯，半径 <8px；紫不作大面积背景；禁止紫色渐变白底。

### 2.3 字体体系

| 层级 | 字体 | 规则 |
|---|---|---|
| 大标题（≥26px） | Bricolage Grotesque + 自托管 Noto Sans SC Display 900 | 字距收紧，两行式主张 |
| 正文 / 题干 | Geist / HarmonyOS Sans / MiSans / PingFang SC | 15–17.5px，对比度 ≥4.5:1 |
| 数字 / 仪器 | IBM Plex Mono（唯一等宽，tabular-nums） | 频率、题号、倒计时、呼号、坐标、S 表、成绩 |
| 仪器小标签 | 全大写 + 字距 `.12em` | 10–12px，配色为低饱和冷灰 |
| 七段读数 | 仅装饰性读数屏 | 不用于正文；非激活段 12% 亮度 |

禁止 Inter / Roboto / Arial / 系统默认字体；禁止假字乱码（文字用占位块或明确短标签）。

### 2.4 组件形态与状态矩阵

### 2.5 动效参数（对齐现有实现）

| 动作 | 时长 | 依据 |
|---|---|---|
| 按压 / 快反馈 | 120ms | `--md-dur-fast`（`tokens.css:257`） |
| 状态切换 / 波段切换 / 进场 | 180ms | `--md-dur`（`:258`） |
| 锁定 / 弹层进场 | 320ms / 180ms | `--md-dur-slow`（`:259`） |
| 点击波纹 / 扫描 | 560ms | `--md-dur-scan`（`tokens.css`）；`style/modern/interaction.css` 的 `.md-ping` |
| 数字滚动 | 760ms / 16 步 | `motion.rs::use_count_up` |
| 换页补登记 | 220ms / 640ms | `RouteTransition` |
| 缓动 | `cubic-bezier(.2,.7,.3,1)` | `--md-ease`（`tokens.css:255`） |
| 降级 | 1ms、内容始终可见 | `prefers-reduced-motion` |

### 2.6 无线电元素清单

同心电波弧、频率刻度尺、频谱柱与瀑布图、S 表指针与 S9 合格线、示波波形与噪声底、1px 扫描线、滚花旋钮刻度、RX/TX/WARN/INFO 指示灯、七段读数屏、发射塔细线、QSL 卡式勋章。全部结构性使用，不作贴纸装饰。

### 2.7 无障碍与直观性

颜色不单独承载语义；每个状态差异在灰度模式下也能辨认（位置 / 描边 / 灯 / 文字至少其一变化）；焦点环画在元素外 2px，容器需留 4px 余量；弹层焦点先给面板、关闭归还触发者、背景滚动锁只有一份、关闭态不拦截点击；`aria-invalid` 只在错误态出现。
