# 现代风类名索引（`md-*`）

> **手工维护**（仓库里没有生成命令）：登记范围是 `crates/app/style/modern/` 下全部 `*.css`
> 声明的 `md-*` 类。`check-structure` 按类名**精确比对**两个方向 —— CSS 里声明了但这里没登记、
> 这里登记了但 CSS 里已经没有（死条目），都会报错。条目写成 `` `md-xxx`(规则数) `` 的形态，
> 第一列的组名只是分组标签，不参与比对；规则数是近似值，不参与比对。

## 约定

- 类名一律 `md-` 前缀；变量一律 `--md-` 前缀（反向隔离由 `check-structure` 保证）。
- 标 ⚠️ 的类只出现在 CSS 里、源码没引用：清理时优先看这一类。
- 组件归属：`md-btn*`→`ui::button`；`md-field*`→`ui::Field`；`md-check*`→`ui::Checkbox`/`ui::RadioGroupItem`；
  `md-switch*`→`ui::Switch`；`md-popover`/`md-option*`→`ui::popover`；`md-dialog-*`→`ui::Dialog`；
  `md-modal*`→`kit_modern::ModernDialog`；`md-table*`→`ui::Table`；`md-link`→`kit::link_class()`（行内文字链接）；`md-link-row`→首页入口列表的一行（`kit_modern::home::module_grid`），两者**不是同一个组件**；
  `md-check-row`→`kit::check_row_class()`。
